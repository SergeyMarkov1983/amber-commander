Amber Commander v1.1 — быстрый двухпанельный файловый менеджер в тёплых тонах
=================================================================================

Портативная версия. Для запуска нужен только amber.exe (настройки
создаются автоматически в файле amber.ini рядом с программой).

Что нового в v1.1
-----------------
* Глобальный индекс каталогов (folders.idx) актуализируется в фоне при
  каждом запуске — по умолчанию. Поиск каталогов работает сразу, пока
  индекс пересобирается; в правом краю командной строки виден серый
  индикатор «индексация поиска…», после завершения на несколько секунд
  появляется «индекс поиска обновлён».
  Отключить: folderIndexRefresh=0 в amber.ini (тогда пересборка только
  если индекс старше недели).
* Исправлено обновление индекса: старый файл индекса больше не остаётся
  заблокированным (memory-mapped), из-за чего folders.idx не заменялся
  и рядом оставался folders.idx.tmp. Теперь индекс гарантированно
  подменяется, а поиск во время пересборки продолжает работать.

Установка в систему (по желанию)
--------------------------------
Один раз выполните:  powershell -ExecutionPolicy Bypass -File install.ps1
После этого:
  * «amber» в поиске меню «Пуск» сразу находит Amber Commander
  * команда amber работает в cmd, PowerShell и Win+R (открывайте новые окна)
  * amber запускается от имени администратора (UAC при каждом запуске) —
    для мгновенного индекса каталогов и быстрых «Размеров» по MFT
    (отключить: удалить значение exe в HKCU\...\AppCompatFlags\Layers)
Если перенесёте папку с программой — запустите install.ps1 заново.

Горячие клавиши
---------------
F2 — переименовать          F3 — просмотр (текст/HEX/изображения)
F4 — правка (Notepad++)     F5 — копирование
F6 — перемещение            F7 — создать каталог
F8 — удаление (в Корзину)   Shift+F4 — новый файл
Shift+F8 — удалить без подтверждения
F9 — меню                   F10 — выход
F11 — размеры каталогов (вид WizTree) — полосы, Enter внутрь, Del удалить
Alt+F7 — поиск              Alt+F1/F2 — выбор диска
Alt+Enter — полный экран    Alt+←/→ — история переходов
Tab — панель                Ctrl+U — обмен панелей
Ctrl+O — скрыть панели      Ctrl+R — обновить
Ctrl+Q — быстрый просмотр в соседней панели (картинки, текст,
         карточка файла с атрибутами; Esc — выключить)
Ctrl+F12 — тема (Янтарь → Кофе/Какао → Холодная → Фосфор → Сталь → FAR → Спектр → Ночной циан → Уголь)
Янтарь — почти чёрный тёплый фон, янтарные акценты, кремовый текст.
Фосфор — тёмный зелёный монитор: ярко-зелёный текст, зелёные рамки,
фосфорный курсор. FAR — классика VGA: синие панели, циановая шапка,
жёлтые папки. Shift+←/→ — ширина панелей
Insert/Space — выделение    Shift+↑/↓ — выделение по мере движения
←/→ — вверх/вход            Backspace — на уровень выше
Ctrl+←/→ — история переходов
Правая кнопка — системное меню Windows 11
Правая кнопка + перетаскивание — переместить файл/папку в каталог под курсором
(цель подсвечивается рамкой)
Alt+F1/F2 — диск: если соседняя панель уже на этом диске — откроется её каталог
Шапка панели — хлебные крошки: клик по сегменту — переход, «›» — подпапки
Командная строка: набор ≥2 символов — поиск каталогов на всех дисках
(Enter — открыть, Esc — закрыть; «cd …» попап не открывает). Индекс каталогов
строится в фоне по MFT — при запуске от администратора покрывает все диски
мгновенно, без прав — только несистемные диски (фоновая сборка ~минуты).
Ctrl+Space — снять всё выделение
Набор текста — живой переход к файлу; Enter — открыть его
или выполнить команду (как Win+R); cd путь — переход

Настройки (amber.ini)
---------------------
Файл создаётся и обновляется автоматически при выходе из программы
(тема, каталоги панелей, размер и позиция окна, настройки — всё
сохраняется). Лежит рядом с amber.exe; если папка exe недоступна для
записи (Program Files и т.п.) — используется %APPDATA%\Amber Commander\amber.ini.

[main]
theme=0/1/2/3/4/5/6/7/8 — тема (0 Янтарь, 1 Кофе, 2 Холодная, 3 Фосфор,
                        4 Сталь, 5 FAR, 6 Спектр, 7 Ночной циан, 8 Уголь)
editor=...           — редактор для F4 (Notepad++ находится сам)
fontFace=...         — шрифт (по умолчанию Segoe UI Variable Text)
fontSize=12          — размер шрифта в пикселях
confirmDelete=1      — подтверждение удаления
confirmOverwrite=1   — подтверждение перезаписи
folderIndexRefresh=1 — актуализировать индекс каталогов при каждом запуске
                       (1 — по умолчанию, 0 — только если индекс старше недели)
winRect=x,y,w,h      — позиция и размер окна (сохраняется само)
winMax=0/1           — развёрнутое окно
Ширина панелей (Shift+←/→) — на время сеанса, при выходе сбрасывается на 50/50

[usermenu]           — своё меню (F9 → Меню пользователя)
1=Блокнот|notepad.exe
2=Каталог Windows|cd C:\Windows
