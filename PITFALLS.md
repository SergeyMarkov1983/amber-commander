# PITFALLS — сигнатура ошибки → причина → фикс

## Индекс не обновляется, остаётся folders.idx.tmp
- **Симптом:** индикатор индексации исчезает, но «индекс поиска обновлён» не появляется; `folders.idx.tmp` остаётся, `folders.idx` не меняется.
- **Причина:** старый индекс остаётся memory-mapped. Windows не позволяет заменить mapped-файл: `MoveFileExW(..., REPLACE_EXISTING)` падает с «файл уже используется», `wrote=false`.
- **Фикс:** перед подменой — под мьютексом `g_ready=false`, `UnmapViewOfFile` + закрыть секцию, затем `MoveFileExW`, затем `MapIndex()+ValidateIndex()` и `g_ready=true`. При неудаче удалить tmp и пересмапить старый индекс.
- **Проверка:** после запуска `LastWriteTime` файла меняется, `.tmp` исчезает. Mapped-файл до Unmap заменить нельзя — проверяется двумя строками PowerShell.

## PowerShell 5.1 ломает кириллицу в .ps1
- **Симптом:** кириллические пути/строки в скрипте превращаются в мусор.
- **Причина:** `.ps1` без BOM читается как ANSI.
- **Фикс:** сохранять скрипты в UTF-8 **с BOM**; в `kit.ps1` BOM уже стоит.
